Política de privacidade

Vale para o aplicativo "Publicação do canal Vultorum", usado só pelo administrador do canal Vultorum.

Que dados o aplicativo acessa

Com a autorização do administrador, o aplicativo usa a API do YouTube para enviar vídeos, definir título, descrição, capa, legenda e data de publicação, criar playlists e publicar comentários no próprio canal. Ele lê apenas os dados desse canal (nome, identificador e estatísticas públicas) para confirmar que está ligado ao canal certo.

Como os dados são guardados

A autorização do Google fica gravada apenas no computador do administrador. Nenhum dado é enviado a servidores do aplicativo nem compartilhado com terceiros. Os vídeos e textos enviados pertencem ao canal.

Como revogar

A qualquer momento, em myaccount.google.com/permissions, remova o acesso do aplicativo. Isso apaga a autorização.

Serviços do Google

O aplicativo usa os serviços da API do YouTube e segue os Termos de Serviço da API do YouTube e a Política de Privacidade do Google (policies.google.com/privacy).
